# Mind Control Gym Management System

A full-stack Gym Management System developed for Mind Control Gym, Sector 49, Faridabad.

The system helps manage gym members, payments, trainers and personalized workout plans through a centralized web application.

## Features

- Admin Login and Authentication
- JWT-based Authentication
- Member Management
- Member Search
- Membership Plan Management
- Payment Management
- Trainer Management
- Workout Plan Management
- Multiple Exercise Management
- Dashboard Statistics
- Recent Members Overview
- Revenue Tracking
- Due Payment Tracking
- Membership Expiry Tracking
- Responsive User Interface

## Technology Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

### Development Tools
- Visual Studio Code
- Postman
- MongoDB Compass
- Git
- GitHub
